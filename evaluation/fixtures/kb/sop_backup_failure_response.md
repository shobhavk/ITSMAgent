# Backup Failure Response SOP

## Purpose
Defines how the Backup Team responds to failed backup jobs.

## Procedure
1. Check the backup job log for the failure reason.
2. Verify the backup repository has at least 15% free space before re-running.
3. Re-run the failed job once. Do not re-run more than once without investigation.
4. If two consecutive runs fail, raise a ticket to the Backup Team and notify the application owner.

## Reporting
Record every failed backup and its resolution in the weekly backup report.
